    범프 차트

    카드 1장높이 2단위

    기간마다 순위를 찍고 S자 곡선으로 이어, 값보다 순서가 어떻게 바뀌었는지를 보여줍니다. 1위가 맨 위이고 이름은 선의 양 끝에 적습니다.

    차트 가이드 · 범프 차트

    Bump - Basic

    bump-basic

    여러 항목의 순위가 기간마다 어떻게 바뀌었는지 한꺼번에 보는 카드입니다. 지사나 상품의 순위 경쟁을 보여줄 때 씁니다.

    들어 있는 판단 3
    • 값(values)을 주면 기간마다 큰 순서로 순위를 매깁니다. 순위는 값의 차이를 감추므로, 차이의 크기가 중요하면 Line - Multiple을 씁니다.
    • 마지막 기간의 상위 세 항목만 주황 · 분홍빨강 · 파랑(라인 차트의 선 색 규칙)으로, 나머지는 회색으로 그립니다.
    • 항목은 여덟 개 안팎까지 둡니다. 더 많으면 선이 얽혀 읽히지 않으니 상위 항목만 남깁니다.
