      Cards/Controls

      Controls

      4 cardsHeight 1 unit

      Controls set the period, ranges and items of a screen and download its data. They send a vzb-change event when the value changes, and a chart card draws again when the JSON inside it changes.

      Range Slider

      control-range

      A control that picks a numeric range with two thumbs. Use it to filter a screen by a continuous value such as an amount or a quantity. The current values always sit in bubbles above the thumbs, and when the thumbs come close the bubbles merge into one range.

      Judgment built in (4)
      • Pick between min and max in steps of step (empty splits the range into about 100 steps). Give the first range in value as [start, end]; empty is the whole range. Values are written by format.
      • The bubbles above the thumbs always show the current values. When the two bubbles come close enough to overlap, they merge into one "start – end" bubble, so the text never overlaps. The two ends that can be picked are written under the track.
      • Each time the value changes, the card sends a vzb-change event. detail.name is name and detail.value is [start, end] as numbers. The current value is also on the card as data-vzb-value.
      • Drag a thumb, press the track to bring the nearer thumb there, or focus a thumb and press the arrow keys to move one step (Page Up and Down about ten steps, Home and End to the end). The thumbs follow the value like a spring and the bubbles lean into the move. With reduced motion turned on, they move at once.

      Date Slider

      control-date

      A control that picks a period with two thumbs. Use it as the date parameter of a whole screen. One step is a month or a day, and putting both thumbs on the same step picks that one month (or day).

      Judgment built in (4)
      • Write min and max as YYYY-MM for one month per step, or as YYYY-MM-DD for one day. Give the first period in value as [start, end] in the same form; empty is the whole period.
      • The bubbles are written short, like Jun '26, and when they come close they merge into one "Jun '26 – Nov '26" bubble. The first and last steps that can be picked are written under the track.
      • Each time the value changes, the card sends a vzb-change event. detail.name is name and detail.value is [start, end] as text in the same form as min; the end is part of the period. The current value is also on the card as data-vzb-value.
      • Drag a thumb, press the track to bring the nearer thumb there, or focus a thumb and press the arrow keys to move one step (Page Up and Down about ten steps, Home and End to the end). The thumbs follow the value like a spring and the bubbles lean into the move. With reduced motion turned on, they move at once.

      Filter Chips

      control-chips

      A control that picks several items from a fixed list as chips. Use it to filter a screen by a few names, such as channels or regions. The All chip at the front shows how many are picked.

      Judgment built in (4)
      • List the items in options and the first picks in value (empty picks all). Past two rows the chips go on one row that scrolls sideways, so about 8 items, all visible at a glance, fit best.
      • The All chip at the front (all; empty means "All", an empty string leaves it out) shows the number picked as a rolling number, and pressing it picks everything, or clears everything when all are picked. How many are on is always in view, so a filter is never left on by mistake.
      • Each time the value changes, the card sends a vzb-change event. detail.name is name and detail.value is the picked items in the order of options. The current value is also on the card as data-vzb-value.
      • A chip squashes a little when pressed and springs back, and when picked a check is drawn as the chip widens. Picked chips are filled with the text color so they do not compete with the data colors of the charts. Tab moves between chips and Space or Enter picks; with reduced motion turned on, they change at once.

      Download Button

      control-download

      A button that downloads the data of a chart card on the screen as a CSV file. Use it to export exactly what the controls show. Give it a shortcut and keycaps appear in the button, so the keyboard downloads too.

      Judgment built in (5)
      • Write the kind of the card to download in target (its data-vzb, e.g. bar-budget). The card takes the first such card on the page and writes its items (or the first array of objects in its JSON) as rows, with their number and text fields as columns. It reads the JSON after the controls changed it, so you get what you see.
      • filename names the file, and a BOM goes at the start so Excel reads non-English text correctly. When there are no rows, the button shakes and briefly says "No data".
      • Before downloading, the card sends a vzb-download event (detail: { name, target, filename, rows }). If the page calls preventDefault() the card makes no file, so a screen that fetches the source data from a server can use the same button.
      • Give a shortcut (e.g. shift+d, mod+shift+e; mod is ⌘ on a Mac and Ctrl elsewhere) and keycaps appear in the button; pressing the keys sinks the caps and downloads. The caps teach the shortcut, and their sinking shows the keys took effect. Use a shortcut only once per page.
      • When the file is saved, the arrow drops into the tray and turns into a check, the label turns into done and the file name turns into the number of rows, coming back after 1.8 s. That way the fact and the size of the download show where the button is. With reduced motion turned on, only the words change.
