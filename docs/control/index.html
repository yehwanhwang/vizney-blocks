      Cards/Controls

      Controls

      3 cardsHeight 1 unit

      Controls set the period, ranges and items of a screen and download its data. They send a vzb-change event when the value changes, and a chart card draws again when the JSON inside it changes.

      Range Slider

      control-range

      A control that picks a numeric range with two thumbs. Use it to filter a screen by a continuous value such as order value or quantity. Give it the distribution of the values and bars over the track show how much data falls in the range as you drag.

      Judgment built in (4)
      • Pick between min and max in steps of step (empty splits the range into about 100 steps). Give the first range in value as [start, end]; empty is the whole range. The picked range is written on the line above, by format.
      • Give counts, the number of records in each equal-width bin from min to max, and bars of that distribution sit over the track: only the bars inside the range take the text color, and the number inside the range rolls next to noun (e.g. orders). Picking by the range alone hides where the data piles up, which makes it easy to filter it away. Matching step to the bin width makes the count exact.
      • Each time the value changes, the card sends a vzb-change event. detail.name is name and detail.value is [start, end] as numbers. The current value is also on the card as data-vzb-value.
      • Drag a thumb, press a bar or the track to bring the nearer thumb there, or focus a thumb and press the arrow keys to move one step (Page Up and Down about ten steps, Home and End to the end). The thumbs follow like a spring; bars rise a little as they enter the range, nearest to the moving thumb first, and dip as they leave. With reduced motion turned on, the thumbs move at once and the bars stay still.

      Filter Chips

      control-chips

      A control that picks several items from a fixed list as chips. Use it to filter a screen by a few names, such as channels or regions. The All chip at the front shows how many are picked.

      Judgment built in (4)
      • List the items in options and the first picks in value (empty picks all). Past two rows the chips go on one row that scrolls sideways, so about 8 items, all visible at a glance, fit best.
      • The All chip at the front (all; empty means "All", an empty string leaves it out) shows the number picked as a rolling number, and pressing it picks everything, or clears everything when all are picked. How many are on is always in view, so a filter is never left on by mistake.
      • Each time the value changes, the card sends a vzb-change event. detail.name is name and detail.value is the picked items in the order of options. The current value is also on the card as data-vzb-value.
      • A chip squashes a little when pressed and springs back, and when picked a check is drawn as the chip widens. Picked chips are filled with the text color so they do not compete with the data colors of the charts. Tab moves between chips and Space or Enter picks; with reduced motion turned on, they change at once.

      Download Button

      control-download

      A button that downloads the data of a chart card on the screen as a file. It starts as an icon alone; hover and the formats to pick from (CSV, JSON, PNG) come out. Use it to export exactly what the controls show.

      Judgment built in (5)
      • Write the kind of the card to download in target (its data-vzb, e.g. bar-budget). The table comes from the current JSON of the first such card on the page: items, else labels with values (adding limit and target as columns when present), labels with series, else the first array of objects. It reads the JSON after the controls changed it, so you get what you see.
      • List the formats in formats (csv, json, png; empty means all three). The CSV starts with a BOM so Excel reads non-English text correctly, and the PNG is the card as you see it at twice the size (its text may be drawn in a font installed on the device). The file name is filename plus the extension of the format.
      • An icon alone takes little room on the screen; hover it, reach it with the keyboard or press it and the button widens and the formats come out one by one. Pressing the icon again while open downloads the first format, Esc closes it, and the left and right arrows move between the formats.
      • Before downloading, the card sends a vzb-download event (detail: { name, target, format, filename, rows }). If the page calls preventDefault() the card makes no file, so a screen that fetches the source data from a server can use the same button.
      • When the file is saved, the arrow drops into the tray and turns into a check, and the format and the number of rows (for a PNG, its size) roll up next to the button and fade after 1.8 s. When there is nothing to download, the button shakes and says "No data". With reduced motion turned on, only the state changes.
