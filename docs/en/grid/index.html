    Cards/Grid Chart

    Grid Chart

    4 cardsHeight 2 units

    Exact numbers in a table. Numbers are right-aligned in tabular figures so the digits line up, column headings sort, and the total row always stays at the bottom.

    Chart guide · Grid chart

    Grid - Basic

    grid-basic

    A basic table that lists several metrics side by side per item, with a total. Use it to report each item's results in a few numbers together.

    Judgment built in (3)
    • The initial order is by the most important number column, largest first (sortKey). Number columns sort largest first, name columns alphabetically, and a second click reverses the order.
    • The total row stays at the bottom whatever the sort. The total of a change column is not the sum or average of the cells; it is recomputed from the totals.
    • Columns are set in columns. "total": "sum" writes the sum, and a "type": "change" column writes the change between the of and base values as the same badge as the KPI cards. For a dollar column, set "format": "usd" and give the raw values: the heading gets $K or $M and the cells get the divided values.

    Grid - Spark

    grid-spark

    A table with a small 13-month line in every row. Use it to skim the latest value and the course of several items at once.

    Judgment built in (3)
    • Each sparkline is drawn to its own row's range, but a range narrower than 10% of the value is widened to 10%, so a nearly flat row does not look like a big swing. Size is compared between rows in the number column.
    • A dot marks the last value at the end of the line, and the same row gives the last value and its change from the first. With 13 months, the change from the first is a year-over-year change.
    • No axis, grid or tooltip. To look closely at one item's course, use Line - Basic or Line - Multiple.

    Grid - Target

    grid-target

    A table with target · actual · attainment in one row and the status marked. Use it to report target and actual amounts as numbers.

    Judgment built in (3)
    • The attainment bar starts at zero, the track ends at the highest attainment, and the vertical tick is the target (100%). Rows past the target grow by the excess too, so the differences between rows show. The bar color matches the status: green or red.
    • The status is written as Met or Missed alongside its color, so it is not told by color alone. The colors are the KPI badge's green and red.
    • Rows are ordered by attainment, and the total row's attainment is recomputed as total actual over total target. For a metric where lower is better, switch with "better": "down".

    Grid - Pivot

    grid-pivot

    A row × column crosstab with row totals and column totals. Use it to show amounts split by two dimensions, like region × channel, as they are.

    Judgment built in (3)
    • Row totals go in the rightmost column and column totals in the bottom row. The bottom-right cell is the grand total.
    • Columns are ordered by total, largest first; with five or more, only the three largest stay and the rest fold into an Other column (the same rule as the donut chart). Columns with a set order keep the written order with "sort": false.
    • Hovering a cell tints its row and column together, so the crossing point is easy to follow.
