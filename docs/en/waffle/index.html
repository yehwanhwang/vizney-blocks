    Waffle - Basic

    waffle-basic

    A card that shows shares as a count of squares out of 100. Use it to convey a share at a size you can count, like 'four squares out of ten'.

    Judgment built in (3)
    • One square is 1%. So the rounded counts add up to 100, one square is added at a time to the items with the largest remainders first.
    • Squares fill from the top left, largest item first, so same-colored squares gather in one block. The square size is set between 10 and 24px to fit the room left on the card, so no large gap remains.
    • The color rule is the same as the donut's. Beyond the three largest items, the rest fold into a gray Other.
