    그리드 차트

    카드 4장높이 2단위

    표로 정확한 숫자를 전합니다. 숫자는 오른쪽 정렬과 같은 폭 숫자로 자릿수를 맞추고, 열 제목을 누르면 정렬하며, 합계 줄은 늘 맨 아래에 둡니다.

    차트 가이드 · 그리드 차트

    Grid - Basic

    grid-basic

    여러 지표를 항목마다 나란히 적고 합계까지 보는 기본 표입니다. 항목별 실적을 몇 가지 숫자로 함께 보고할 때 씁니다.

    들어 있는 판단 3
    • 처음에는 가장 중요한 숫자 열의 큰 순서로 둡니다(sortKey). 숫자 열은 큰 순서부터, 이름 열은 가나다순부터 정렬하고 다시 누르면 반대로 바뀝니다.
    • 합계 줄은 정렬과 상관없이 맨 아래에 둡니다. 증감률 열의 합계는 칸의 증감률을 더하거나 평균하지 않고 합계끼리 다시 계산합니다.
    • 열은 columns에 적습니다. "total": "sum"이면 합을 적고, "type": "change" 열은 of와 base 두 값의 증감률을 KPI 카드와 같은 배지로 적습니다.

    Grid - Spark

    grid-spark

    줄마다 13개월 흐름을 작은 선으로 넣은 표입니다. 여러 항목의 최근 값과 흐름을 한 번에 훑을 때 씁니다.

    들어 있는 판단 3
    • 작은 선은 줄마다 자기 범위에 맞춰 그리되, 범위가 값의 10%보다 좁으면 10%로 넓혀 거의 변하지 않은 줄이 크게 출렁여 보이지 않게 합니다. 줄끼리의 크기 비교는 숫자 열로 합니다.
    • 선 끝에 마지막 값을 점으로 찍고, 같은 줄에 마지막 값과 첫 값 대비 증감을 적습니다. 13개월이면 첫 값 대비가 전년 동월 대비가 됩니다.
    • 축 · 격자 · 툴팁은 두지 않습니다. 한 항목의 흐름을 자세히 봐야 하면 Line - Basic이나 Line - Multiple을 씁니다.

    Grid - Target

    grid-target

    목표 · 실적 · 달성률을 한 줄에 적고 달성 여부를 표시한 표입니다. 목표와 실적 금액까지 숫자로 보고할 때 씁니다.

    들어 있는 판단 3
    • 달성률 칸의 막대는 0에서 시작하고, 바탕 끝은 가장 높은 달성률, 세로 눈금은 목표(100%)입니다. 목표를 넘은 줄도 넘은 만큼 길어져 줄 사이의 차이가 보입니다. 막대 색은 상태와 같은 초록 · 빨강입니다.
    • 상태는 색과 함께 달성 · 미달 글자로 적어, 색만으로 구분하지 않게 합니다. 색은 KPI 배지와 같은 초록 · 빨강입니다.
    • 달성률이 높은 순서로 두고, 합계 줄의 달성률은 실적 합계를 목표 합계로 나눠 다시 계산합니다. 낮을수록 좋은 지표는 "better": "down"으로 바꿉니다.

    Grid - Pivot

    grid-pivot

    행 × 열 교차표에 행 합계와 열 합계를 함께 둔 표입니다. 권역 × 채널처럼 두 기준으로 나눈 금액을 그대로 보여줄 때 씁니다.

    들어 있는 판단 3
    • 오른쪽 끝 열에 행 합계, 맨 아래 줄에 열 합계를 둡니다. 오른쪽 아래 칸이 전체 합계입니다.
    • 열은 합계가 큰 순서로 두고, 다섯 개 이상이면 큰 세 열만 남기고 나머지는 기타 열로 묶습니다(도넛 차트와 같은 규칙). 순서가 정해진 열은 "sort": false로 적은 순서를 지킵니다.
    • 칸에 마우스를 올리면 같은 행과 열을 함께 칠해, 교차하는 위치를 따라가기 쉽게 합니다.
