      Blocks

      Charts for the changes you only see in motion, such as a limit crossed, a rank overtaken or a share that grew, and the controls a dashboard needs. Each card is one HTML snippet: paste it in and change only the JSON.

      How to use

      Nothing to install. One card is an HTML snippet that carries its own styles, data and script.

      1. 1

        Copy and paste

        Press Copy code on a card and paste it anywhere inside the <body> of your HTML.

        <div class="vzb-card"
  data-vzb="warning-bars">
  …
</div>
      2. 2

        Change only the JSON

        Edit the values in the card’s JSON. The card computes the amount over the limit, the shares and the ranks.

        "limit": 40000,
"labels": ["Nov '25", …],
"values": [34200, …]
      3. 3

        Connect a control

        A control sends a vzb-change event when its value changes. Rewrite the JSON text inside a chart card from that value and the card draws again. #spend below is an element wrapped around the chart card code.

        document.addEventListener(
  'vzb-change', (e) => {
  const src = document
    .querySelector(
      '#spend script');
  const d = JSON.parse(
    src.textContent);
  // from the picked values
  d.values =
    totals(e.detail.value);
  src.textContent =
    JSON.stringify(d);
});
      4. 4

        Hand it to an AI

        Paste a card’s Copy prompt (rules and code together) into a chat AI. Give llms.txt to an AI that can open addresses, and install the skill in a coding agent.

        blocks.vizney.com/
  llms.txt

npx skills add
  yehwanhwang/vizney-blocks
      Common fields and layout
      title
      What the values are; the head of a chart card.
      subtitle
      The period and the basis: what is measured, and as of when.
      format
      usd dollar amounts, shortened to $745.6K · $1.2M; count a count (its unit in unit); pct a percentage (changes in pp); days a number of days; eok and krw are Korean won notations (krw writes amounts under 100,000 won in full)
      decimals
      Decimal places of the numbers. Left empty, the card decides.
      better
      up, down, neutral. Says whether more or less is the good direction.
      labels
      Period names, the same length as values; use null as the value of a period without one.
      theme
      dark draws the card on Vizney black with yellow as the first color. Empty is white with blue.
      lang
      en makes the words the card prints itself English (over, vs, tooltips). Omit it for Korean.
      label
      On a control, the name screen readers read. A control draws no title, so always write it.
      name
      The detail.name of the events a control sends; it tells which control changed.

      Several cards in a row

      Cards do not lay themselves out. Give the wrapper a grid and the rows wrap to the width. Keep a chart card at least 340px wide, and give a chart that reads along a long axis two columns or the full width. Every chart card is now 2 units tall (336px), so a mixed row lines up. The controls have no frame, so put them as they are in a filter bar above the charts.

      <div style="display:grid;
  grid-template-columns:
    repeat(auto-fit,
      minmax(min(100%, 340px), 1fr));
  gap:16px;">
  <!-- several chart cards -->
</div>

      Colors, font and background

      Set colors and the font with :root variables; they apply to every card at once. The list is in tokens.css. For a dark screen, write "theme": "dark" in each card’s JSON.

      :root {
  --vzb-primary: #5856d6;
  --vzb-font: 'Pretendard';
}

      Good to know

      • A chart card plays once when it comes into view and stops on its last frame. With reduced motion turned on, it draws the last frame without playing.
      • When the JSON text inside a card changes, only that card draws again, without playing from the start.
      • A card is a snippet pasted into the HTML as it is. Inserted with innerHTML, its script does not run.

      Every card’s rules and how to connect the controls are in llms.txt.
