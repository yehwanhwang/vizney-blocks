      Blocks

      Hard-to-build charts in a single paste. Sankey, bump, funnel and waterfall charts, the kind that need layout math to draw, each in one HTML snippet. Copy it, paste it and change only the JSON.

      • Sankey - LevelsSankey Chart
      • Bump - BasicBump Chart
      • Funnel - FlowFunnel Chart
      • Treemap - BasicTreemap Chart
      • Waterfall - SubtotalWaterfall Chart
      • Radar - BasicRadar Chart
      • Sankey - BasicSankey Chart
      • Scatter - ConnectedScatter Chart
      • Waterfall - BasicWaterfall Chart

      How to use

      Nothing to install. One card is an HTML snippet that carries its own styles, data and script.

      1. 1

        Copy and paste

        Press Copy code on a card and paste it anywhere inside the <body> of your HTML.

        <div class="vzb-card"
     data-vzb="bar-basic">
  …
</div>
      2. 2

        Change only the JSON

        Edit the values in the card’s JSON. The card computes changes, shares and attainment.

        "title": "Orders by Quarter",
"format": "count",
"labels": ["1Q26", "2Q26", "3Q26"],
"values": [2561, 2654, 2750]
      3. 3

        Tune with variables

        Set colors and the font with :root variables; they apply to every card at once. The list is in tokens.css.

        :root {
  --vzb-primary: #0f766e;
  --vzb-font: 'Pretendard';
}
      4. 4

        Hand it to an AI

        Paste a card’s Copy prompt (rules and code together) into a chat AI, or give it the AI link if it can open addresses; install the skill in a coding agent. The skill shows a design table (row · question · card) before writing card code and checks the result against a checklist. Get new judgment with npx skills update.

        blocks.vizney.com/cards/
  bar-basic.txt
Draw our monthly sales by
branch with this card

npx skills add

      Common fields and layout
      title
      Metric name
      subtitle
      Period subtitle: what is measured, and as of when.
      value
      The headline figure of a KPI card. KPI - Line and KPI - Bar use the last value when it is omitted.
      format
      usd dollar amounts, shortened to $745.6K · $1.2M; count a count (its unit in unit); pct a percentage (changes in pp); days a number of days; eok and krw are Korean won notations (krw writes amounts under 100,000 won in full)
      decimals
      Decimal places of the numbers. Left empty, the card decides; pct changes (pp) follow it too.
      better
      up, down, neutral. Decides whether a change is colored green or red.
      compare
      { "label", "value" }. The baseline a KPI card computes its change against.
      labels
      Period names, the same length as values; use null for a period without a value.
      series
      [{ "name", "values" }], for several lines or groups of bars.
      rows
      Rows of a table or list, each with a name and its values. The card computes the total row, shares, change rates and attainment.
      curve
      Line shape: smooth (default), linear, step. Used by the line cards and KPI - Line.
      lang
      en makes the words the card prints itself English (Total, Other, Met…). Omit it for Korean.

      Several cards in a row

      Cards do not lay themselves out. Give the wrapper a grid and the rows wrap to the width. Keep each card at least 340px wide; narrower, the text in tables and donuts clips. A row of KPI cards alone can go down to 280px, so four fit across a 1280px page. Cards in a row stretch to the tallest one, so a row of equal-height cards leaves no gaps.

      <div style="display:grid;
  grid-template-columns:
    repeat(auto-fit,
      minmax(min(100%, 340px), 1fr));
  gap:16px;">
  <!-- several cards -->
</div>

      Picking and layout

      • Up to four KPI cards per row.
      • Bar lists and tables fit 2 units up to six rows. Longer ones go in a row with cards of the same row count.
      • When a share card’s Other is larger than its third slice, use Bar - Ranking.
      • Give the full width only to cards whose width carries information (a 13-month line with several series, a wide table or heatmap, a long waterfall, a sankey).
      • No group headings between card rows: one screen title and one line for the date and source.
