      컨트롤

      카드 3장높이 조작부 높이

      화면의 범위 · 항목을 고르고 데이터를 내려받는 조작부입니다. 제목과 틀 없이 조작부만 그려 원하는 자리에 놓습니다. 값이 바뀌면 vzb-change 이벤트를 보내고, 차트 카드는 안의 JSON이 바뀌면 다시 그려집니다.

      Range Slider

      control-range

      손잡이 둘로 숫자 범위를 고르는 컨트롤입니다. 주문 금액이나 수량처럼 이어지는 값으로 화면을 거를 때 씁니다. 값의 분포를 주면 끄는 동안 레일 위에 막대로 떠올라, 고른 범위에 데이터가 얼마나 드는지 보여 줍니다.

      들어 있는 판단 4
      • min과 max 사이를 step 간격으로 고릅니다(step을 비우면 범위를 100칸쯤으로 나눕니다). value에 처음 범위 [시작, 끝]을 적고, 비우면 전체 범위입니다. 고른 값은 format대로 손잡이 아래에 붙어 따라가고, 두 값이 겹치면 '시작 – 끝' 하나로 합칩니다.
      • counts에 min~max를 같은 폭으로 나눈 칸마다의 개수를 적으면, 끄는 동안과 키보드로 옮기는 동안만 레일 위에 분포 창이 떠올라 고른 범위 안의 막대를 글자색으로 채우고 범위 안의 개수를 적습니다(단위는 noun, 비우면 행). 범위만 보고 고르면 데이터가 몰린 곳을 모르고 거르기 쉽기 때문이고, 가만히 둘 때는 레일과 값만 남겨 필터 줄에서 자리를 적게 차지합니다. step을 칸 폭에 맞추면 개수를 정확히 셉니다.
      • 값이 바뀔 때마다 vzb-change 이벤트를 보냅니다. detail.name은 name, detail.value는 [시작, 끝] 숫자입니다. 지금 값은 카드의 data-vzb-value에도 있습니다.
      • 손잡이를 끌거나, 레일을 눌러 가까운 손잡이를 옮기거나, 포커스한 뒤 화살표 키로 한 칸씩 옮깁니다(Page Up · Down은 열 칸쯤, Home · End는 끝). 손잡이는 용수철처럼 따라가고, 막대는 범위에 들어오면 손잡이에서 가까운 차례로 살짝 솟고 나가면 살짝 꺼집니다. 동작 줄이기 설정에서는 바로 옮기고 분포 창과 막대도 움직이지 않습니다.

      Filter Chips

      control-chips

      정해 둔 항목 가운데 여러 개를 칩으로 고르는 컨트롤입니다. 채널이나 지역처럼 몇 개 안 되는 이름으로 화면을 거를 때 씁니다. 맨 앞의 전체 칩이 지금 몇 개를 골랐는지 보여 줍니다.

      들어 있는 판단 4
      • options에 고를 항목을 적고 value에 처음 고른 항목을 적습니다(비우면 모두). 칩이 두 줄을 넘으면 한 줄로 두고 가로로 밀어 보게 하므로, 한눈에 다 보이는 8개 안팎까지가 알맞습니다.
      • 맨 앞의 전체 칩(all, 비우면 '전체', 빈 글자면 없음)은 고른 수를 굴러가는 숫자로 보여 주고, 누르면 모두 고르거나 이미 모두 골랐으면 모두 풉니다. 몇 개가 걸려 있는지가 늘 보여 필터를 건 채로 잊지 않습니다.
      • 값이 바뀔 때마다 vzb-change 이벤트를 보냅니다. detail.name은 name, detail.value는 고른 항목을 options 순서대로 담은 배열입니다. 지금 값은 카드의 data-vzb-value에도 있습니다.
      • 칩은 누르면 살짝 눌렸다 튀어 오르고, 고르면 체크가 그려지며 칩이 넓어집니다. 고른 칩은 글자색으로 채워 차트의 데이터 색과 겨루지 않습니다. Tab으로 칩을 옮기고 Space나 Enter로 고르며, 동작 줄이기 설정에서는 바로 바뀝니다.

      Download Button

      control-download

      화면에 있는 차트 카드의 데이터를 파일로 내려받는 단추입니다. 처음에는 아이콘만 있고, 마우스를 올리면 CSV · JSON · PNG 가운데 받을 형식이 나옵니다. 컨트롤로 거른 지금 데이터를 그대로 받을 때 씁니다.

      들어 있는 판단 5
      • target에 내려받을 카드의 종류(data-vzb, 예: bar-budget)를 적습니다. 페이지에서 처음 만나는 그 카드의 지금 JSON에서 표를 만듭니다: items, 없으면 labels와 values(limit · target이 있으면 열로 더함), labels와 series, 그 밖에는 처음 나오는 객체 배열입니다. 컨트롤로 거른 뒤의 JSON을 읽으므로 보이는 그대로 받습니다.
      • formats에 받을 형식을 적습니다(csv · json · png, 비우면 셋 다). CSV는 엑셀에서 한글이 깨지지 않게 BOM을 붙이고, PNG는 카드를 보이는 그대로 2배 크기 그림으로 받습니다(글꼴은 기기에 설치된 것으로 그려질 수 있습니다). 파일 이름은 filename에 형식의 확장자를 붙입니다.
      • 처음에는 아이콘만 두어 화면에서 자리를 적게 차지하고, 마우스를 올리거나 키보드로 들어오거나 아이콘을 누르면 단추가 늘어나며 형식이 차례로 나옵니다. 열린 상태에서 아이콘을 다시 누르면 첫 형식으로 받고, Esc는 닫으며, 좌우 화살표는 형식 사이를 옮깁니다. 늘어난 단추는 옆 내용 위로 겹쳐 떠서 자리를 밀어내지 않고, 오른쪽에 펼칠 자리가 없으면 아이콘은 그대로 둔 채 왼쪽으로 펼칩니다. 화면 오른쪽 위처럼 오른쪽 끝에 둘 때는 align을 end로 적으면 아이콘을 오른쪽 끝에 붙이고 왼쪽으로 펼칩니다.
      • 받기 전에 카드에서 vzb-download 이벤트(detail: { name, target, format, filename, rows })를 보냅니다. 페이지가 preventDefault()를 부르면 카드는 파일을 만들지 않으므로, 서버에서 원본을 받는 화면도 같은 단추를 쓸 수 있습니다.
      • 받으면 화살표가 받침으로 떨어져 체크로 바뀌고, 옆에 받은 형식과 행 수(PNG는 그림 크기)가 굴러 올라왔다가 1.8초 뒤 사라집니다. 받을 데이터가 없으면 단추가 좌우로 떨고 '데이터 없음'을 적습니다. 동작 줄이기 설정에서는 움직임 없이 상태만 바뀝니다.
