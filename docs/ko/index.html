      Blocks

      움직임으로 읽는 차트와 대시보드 컨트롤을 HTML 조각 하나씩에 담았습니다. 한도를 넘긴 값은 깜빡여 알리고, 기간과 범위는 슬라이더로 고르며, 데이터가 바뀌면 차트가 그 자리에서 다시 그려집니다. 복사해 붙이고 JSON 값만 바꾸세요.

      • Budget Bars
      • Range Slider
      • Date Slider

      쓰는 법

      설치할 것은 없습니다. 카드 하나가 스타일, 데이터, 스크립트를 모두 담은 HTML 조각입니다.

      1. 1

        복사해서 붙이기

        카드의 코드 복사를 눌러 HTML의 <body> 안 원하는 자리에 붙여 넣습니다.

        <div class="vzb-card"
     data-vzb="bar-budget">
  …
</div>
      2. 2

        JSON만 바꾸기

        카드 안 JSON의 값만 바꿉니다. 증감, 비중, 달성률은 카드가 계산합니다.

        "title": "분기별 출고 금액",
"format": "eok",
"labels": ["1Q26", "2Q26", "3Q26"],
"values": [2561, 2654, 2750]
      3. 3

        변수로 맞추기

        색과 글꼴은 :root의 변수로 바꿉니다. 모든 카드에 한 번에 적용됩니다. 변수 목록은 tokens.css에 있습니다.

        :root {
  --vzb-primary: #5856d6;
  --vzb-font: 'Pretendard';
}
      4. 4

        AI에게 맡기기

        채팅 AI에는 카드의 프롬프트 복사로 규칙과 코드를 함께 붙여 넣거나, 주소를 열 수 있으면 AI용 링크를 줍니다. 코딩 에이전트에는 스킬을 설치합니다. 스킬은 카드 코드를 쓰기 전에 설계표(줄 · 질문 · 카드)를 보여 주고, 다 만든 뒤 체크리스트로 확인합니다. 새 판단은 npx skills update로 받습니다.

        blocks.vizney.com/ko/cards/
  bar-basic.txt
이 카드로 지점별 월 매출을
그려줘

npx skills add
  yehwanhwang/vizney-blocks
      공통 필드와 여러 장 배치
      title
      지표명
      subtitle
      기간 부제. 무엇을 언제 기준으로 보는지 적습니다.
      value
      KPI 카드의 대표 수치. KPI - Line과 KPI - Bar는 생략하면 마지막 값을 씁니다.
      format
      eok 억 단위 값, krw 원 단위 값을 만·억·조로(10만 원 미만은 87,324원처럼 원 단위 그대로), usd 달러 값을 $745.6K·$1.2M처럼, count 개수(unit에 단위), pct 비율(증감은 %p), days 일수
      decimals
      숫자의 소수 자릿수. 비우면 카드가 정하고, pct의 증감(%p)도 이 자릿수를 따릅니다.
      better
      up, down, neutral. 증감을 초록과 빨강 중 무엇으로 칠할지 정합니다.
      compare
      { "label", "value" }. KPI 카드에서 증감을 계산할 비교 기준입니다.
      labels
      기간 이름. values와 같은 길이로 적고, 값이 없는 기간은 null로 둡니다.
      series
      [{ "name", "values" }]. 선이나 막대를 여러 묶음 그릴 때 씁니다.
      rows
      표와 목록의 줄. 줄마다 name과 값을 적습니다. 합계 줄과 비중, 증감률, 달성률은 카드가 계산합니다.
      curve
      선 모양. smooth(기본) 곡선, linear 직선, step 계단. 라인 카드와 KPI - Line에서 씁니다.
      lang
      en이면 카드 안의 합계 · 기타 · 달성 같은 문구가 영어가 됩니다. 비우면 한국어입니다.

      여러 장을 한 줄에

      카드는 배치를 맡지 않습니다. 감싸는 요소에 격자를 주면 폭에 맞춰 줄이 바뀝니다. 카드 폭은 340px 이상이 되게 두세요. 더 좁으면 표와 도넛의 글자가 잘립니다. KPI 카드만 둔 줄은 280px까지 줄여도 되어, 폭 1280px 화면에 네 장이 한 줄에 들어갑니다. 같은 줄의 카드는 가장 높은 카드에 맞춰 늘어나므로, 높이가 같은 카드끼리 한 줄에 두면 빈 곳이 없습니다.

      <div style="display:grid;
  grid-template-columns:
    repeat(auto-fit,
      minmax(min(100%, 340px), 1fr));
  gap:16px;">
  <!-- 카드 여러 장 -->
</div>

      고르기와 배치

      • KPI 카드는 한 줄에 네 장까지 둡니다.
      • 바 리스트와 표는 여섯 줄까지 2단위에 들어갑니다. 더 길면 줄 수가 같은 카드끼리 한 줄에 둡니다.
      • 비중 카드의 기타가 셋째 조각보다 크면 Bar - Ranking을 씁니다.
      • 전체 폭은 폭이 정보량인 카드(여러 선의 13개월 라인, 열이 많은 표·히트맵, 항목이 많은 워터폴, 생키)에만 줍니다.
      • 카드 사이에 묶음 제목을 두지 않습니다. 화면 제목과 기준일·출처 한 줄이면 됩니다.

      AI가 이 카드로 대시보드를 만든 실험에서 어긋난 자리를 규칙으로 옮겼습니다. 이유와 숫자는 llms.txt에 있습니다.
