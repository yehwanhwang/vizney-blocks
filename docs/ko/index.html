      Blocks

      움직임으로 더 잘 읽히는 차트와 대시보드 컨트롤입니다. 한도를 넘긴 값, 뒤바뀐 순위처럼 변화를 보여 주기도 하고, 짚을 곳에 눈이 가게 하기도 합니다. 카드 하나가 HTML 조각 하나라서, 복사해 붙이고 JSON 값만 바꾸면 됩니다.

      쓰는 법

      설치할 것은 없습니다. 카드 하나가 스타일, 데이터, 스크립트를 모두 담은 HTML 조각입니다.

      1. 1

        복사해서 붙이기

        카드의 코드 복사를 눌러 HTML의 <body> 안 원하는 자리에 붙여 넣습니다.

        <div class="vzb-card"
  data-vzb="bar-overflow">
  …
</div>
      2. 2

        JSON만 바꾸기

        카드 안 JSON의 값만 바꿉니다. 넘친 양, 비중, 순위는 카드가 계산합니다.

        "limit": 40000000,
"labels": ["25.11", …],
"values": [34200000, …]
      3. 3

        컨트롤과 잇기

        컨트롤은 값이 바뀌면 vzb-change 이벤트를 보냅니다. 그 값으로 차트 카드 안 JSON의 글자를 바꾸면 카드가 다시 그려집니다. 아래의 #spend는 차트 카드 코드를 감싼 요소입니다.

        document.addEventListener(
  'vzb-change', (e) => {
  const src = document
    .querySelector(
      '#spend script');
  const d = JSON.parse(
    src.textContent);
  // 고른 값으로 다시 계산
  d.values =
    totals(e.detail.value);
  src.textContent =
    JSON.stringify(d);
});
      4. 4

        AI에게 맡기기

        채팅 AI에는 카드의 프롬프트 복사로 규칙과 코드를 함께 붙여 넣습니다. 주소를 열 수 있는 AI에는 llms.txt 주소를 주고, 코딩 에이전트에는 스킬을 설치합니다.

npx skills add

      공통 필드와 배치
      title
      무엇의 값인지. 차트 카드의 머리에 적습니다.
      subtitle
      기간과 기준. 무엇을 언제 기준으로 보는지 적습니다.
      format
      krw 원 단위 값을 만·억·조로(10만 원 미만은 87,324원처럼 원 단위 그대로), eok 억 단위 값, usd 달러 값을 $745.6K·$1.2M처럼, count 개수(unit에 단위), pct 비율(증감은 %p), days 일수
      decimals
      숫자의 소수 자릿수. 비우면 카드가 정합니다.
      better
      up, down, neutral. 늘어난 것과 줄어든 것 가운데 어느 쪽이 좋은지 정합니다.
      labels
      기간 이름. values와 같은 길이로 적고, 값이 없는 기간은 값을 null로 둡니다.
      theme
      dark면 Vizney 검정 바탕에 노랑을 첫째 색으로 그립니다. 비우면 흰 바탕에 파랑입니다.
      lang
      en이면 카드가 직접 적는 문구(초과, 대비, 툴팁)가 영어가 됩니다. 비우면 한국어입니다.
      label
      컨트롤에서 화면 낭독기가 읽는 이름. 컨트롤은 제목을 그리지 않으므로 꼭 적습니다.
      name
      컨트롤이 보내는 이벤트의 detail.name. 어느 컨트롤이 바뀌었는지 가릅니다.

      여러 장을 한 줄에

      카드는 배치를 맡지 않습니다. 감싸는 요소에 격자를 주면 폭에 맞춰 줄이 바뀝니다. 차트 카드의 폭은 340px 이상으로 두고, 가로로 길게 읽는 차트에는 두 칸이나 전체 폭을 주세요. 지금 있는 차트 카드는 높이가 모두 2단위(336px)라 한 줄에 섞어도 높이가 맞습니다. 컨트롤은 틀이 없으므로 차트 위 필터 줄에 그대로 놓습니다.

      <div style="display:grid;
  grid-template-columns:
    repeat(auto-fit,
      minmax(min(100%, 340px), 1fr));
  gap:16px;">
  <!-- 차트 카드 여러 장 -->
</div>

      색 · 글꼴 · 움직임 · 바탕

      색과 글꼴, 움직임(눌린 단추가 튀는 정도, 막대가 차오르는 빠르기, 시작 전의 뜸)은 :root의 변수로 바꿉니다. 모든 카드에 한 번에 적용되고, 변수 목록은 tokens.css에 있습니다. 어두운 화면에는 카드마다 JSON에 "theme": "dark"를 적습니다.

      :root {
  --vzb-primary: #5856d6;
  --vzb-font: 'Pretendard';
}

      알아 둘 것

      • 차트 카드는 화면에 보이면 한 번 재생하고 마지막 장면에서 멈춥니다. 움직임이 데이터의 뜻이라 운영체제의 동작 줄이기 설정과 상관없이 재생합니다.
      • 카드 안 JSON의 글자가 바뀌면 그 카드만 다시 그립니다. 이때는 처음부터 재생하지 않고, Bar Overflow의 막대와 Funnel Wave의 물은 화면에 있던 높이에서 새 값으로 옮겨 갑니다.
      • 카드는 HTML에 그대로 붙이는 조각입니다. innerHTML로 넣으면 카드의 스크립트가 실행되지 않습니다.

      카드마다의 규칙과 컨트롤을 잇는 법은 llms.txt에 모두 있습니다.
