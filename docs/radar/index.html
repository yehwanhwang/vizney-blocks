    레이더 차트

    카드 1장높이 2단위

    여러 항목의 점수를 한 다각형으로 이어 강점과 약점을 한눈에 보여줍니다. 항목마다 단위가 다르면 0–100점처럼 같은 범위로 환산해 적습니다.

    차트 가이드 · 레이더 차트

    Radar - Basic

    radar-basic

    한 대상의 항목별 점수를 비교 기준과 겹친 카드입니다. 대리점 평가처럼 한 대상이 평균보다 어디서 강하고 약한지 볼 때 씁니다.

    들어 있는 판단 3
    • 비교 기준은 series에서 "base": true로 적습니다. 기준은 옅은 회색 면에 회색 테두리로 아래에 깔고, 대상은 옅은 주황 면에 주황 테두리로 그 위에 겹칩니다. 꼭짓점 점은 찍지 않습니다.
    • 카드 폭이 넉넉하면 오른쪽 목록에 항목별 점수와 기준 대비 배지를 적고, 좁으면 꼭짓점 이름 옆에 점수를 적습니다. 툴팁에는 기준과의 차이를 적습니다.
    • 항목은 다섯에서 여덟 개 사이로 둡니다. 눈금 끝은 max로 정하고, 비우면 값을 감싸는 끝수 없는 값입니다.
