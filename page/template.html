분석가의 판단을 담은 대시보드 카드 모음입니다. 카드를 골라 복사해 HTML에 붙여 넣으면 바로 그려지고, 데이터는 카드 안의 JSON만 바꾸면 됩니다. 차트는 Vizney 차트 가이드의 차트 이름으로 묶었고, 각 묶음에서 같은 차트의 가이드 글로 이어집니다.

쓰는 법

  1. 카드의 복사를 눌러 HTML의 <body> 안 원하는 자리에 붙여 넣습니다. 카드는 놓인 자리의 폭을 채우고, 높이는 내용에 맞춰 정해집니다.
  2. 카드 안 <script type="application/json">의 값만 바꿉니다. 증감, 달성률, 비중은 카드가 계산합니다.
  3. 색과 글꼴은 변수로 바꿉니다. 내 페이지의 :root에 같은 변수를 다시 적으면 모든 카드에 적용됩니다.
:root {
  --vzb-primary: #0f766e;        /* 선, 막대, 게이지 */
  --vzb-primary-tint: #e3f3f1;   /* 트랙, 옅은 바탕 */
  --vzb-unit: 180px;             /* Number 높이, Line · Bar 2배, 나머지 1.5배 */
  --vzb-font: 'Pretendard', sans-serif;
}

공통 필드

title
지표명
subtitle
기간 부제. 무엇을 언제 기준으로 보는지 적습니다.
value
KPI 카드의 대표 수치. KPI - Line과 KPI - Bar는 생략하면 마지막 값을 씁니다.
format
eok 억 단위 값, krw 원 단위 값을 만·억·조로, count 개수(unit에 단위), pct 비율(증감은 %p), days 일수
better
up, down, neutral. 증감을 초록과 빨강 중 무엇으로 칠할지 정합니다.
compare
{ "label", "value" }. KPI 카드에서 증감을 계산할 비교 기준입니다.
labels
라인 카드의 기간 이름. values와 같은 길이로 적고, 값이 없는 기간은 null로 둡니다.
series
[{ "name", "values" }]. 선을 여러 개 그리는 라인 카드에서 씁니다.
rows
그리드 차트와 히트맵 차트의 줄. 줄마다 name과 값을 적습니다. 합계 줄과 비중, 증감률, 달성률은 카드가 계산합니다.
curve
선 모양. smooth(기본) 곡선, linear 직선, step 계단. 라인 카드와 KPI - Line에서 씁니다.

여러 장을 한 줄에

카드는 배치를 맡지 않습니다. 감싸는 요소에 격자를 주면 폭에 맞춰 줄이 바뀝니다.

<div style="display:grid; grid-template-columns:repeat(auto-fit, minmax(240px, 1fr)); gap:16px;">
  <!-- 카드 여러 장 -->
</div>
