# v0.35 · KPI 높이와 워터폴 겹침 수정, 스킬에 설계표와 체크리스트

AI가 이 카드로 대시보드를 만든 실험(요청 3건 × 모델 2종)에서 찾은 카드 결함을 고치고, 스킬에 확인 단계를 더했습니다.

## 카드
- **KPI 카드 높이:** 좁은 폭에서 비교 문구가 내려가며 카드가 168→190px로 늘던 것을 고쳤습니다. 배지는 숫자 바로 뒤에 두고 비교 문구만 아래 줄로 내려, 1단위(168px)를 지킵니다. KPI - Stacked Bar도 1.5단위를 지킵니다. 실험 결과물 6개 가운데 KPI - Number를 쓴 5개에서 모두 늘어났던 높이입니다.
- **%p 증감:** 전환율 1.12%→1.16%가 "0.0%p"로 뭉개지던 것을 0.03%p로 적습니다. `decimals`를 따르고, 0.0으로 보이면 자리를 늘립니다.
- **워터폴:** 바닥선에 붙은 빼는 항목의 값(−21억 · −52억)이 가로축 이름과 겹치면 막대 위에 적습니다.
- **히트맵:** 요일 7행이 2단위에 들어갑니다(354→336px). 8행까지 같은 높이입니다.

## 스킬과 규칙
- 순서 8단계: 질문 → 확인·가정 → 카드 고르기 → 설계표 → 내려받기 → JSON 바꾸기 → 붙이기 → 체크리스트. 카드 코드를 쓰기 전에 「줄 · 질문 · 카드 · 높이」 설계표와 가정을 먼저 보여 줍니다. `better`를 잘못 짐작하면 증감 색이 거꾸로 나오기 때문입니다.
- KPI 카드만 둔 줄의 최소 폭 300→280px. 300px이면 1280px 화면에 네 장이 들어가지 않아, 실험한 에이전트 6개가 모두 격자를 따로 짰습니다.
- 공통 필드에 `decimals`.
