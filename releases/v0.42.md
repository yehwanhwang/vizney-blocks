# v0.42 · 스킬 입구를 영어판으로

- `SKILL.md`를 영어판으로 바꾸고, 한국어판은 `SKILL.ko.md`로 옮겼습니다. 이전의 `SKILL.en.md`는 없앴습니다.
- 이유: skills.sh와 OpenDesign은 `SKILL.md`의 설명으로 스킬을 찾고 고르는데, 두 곳 모두 영어권 사용자가 대부분이고 OpenDesign 플러그인 설명도 영어가 기본입니다. 입구가 한국어면 영어 요청에서 스킬이 덜 골라집니다.
- 한국어 요청도 그대로 받습니다. 스킬 설명 끝에 한국어 한 줄을 두었고, `SKILL.md` 첫머리가 한국어로 일할 때 `SKILL.ko.md`를 따르게 합니다. 두 파일은 같은 원본에서 만들어져 단계, 목적 색인, 규칙, 체크리스트가 같습니다.
- 설치 명령(`npx skills add yehwanhwang/vizney-blocks`), 스킬 이름, 플러그인 ID는 그대로입니다. 설치한 사람은 `npx skills update`로 받습니다.
