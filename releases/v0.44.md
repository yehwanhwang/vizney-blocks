# v0.44 · 프롬프트 복사: 규칙과 코드를 한 번에 채팅 AI로

- 카드의 복사 메뉴에 **프롬프트 복사**(Copy prompt)를 더했습니다. 순서는 카드 코드 복사 · 프롬프트 복사 · AI용 링크 복사입니다.
- 복사되는 것: 요청 한 줄과 그릴 내용을 적는 자리, 쓰는 법 4줄(코드는 그대로 두고 JSON만 바꾸기, 원래 값 넣기, 여러 장 쓰는 법, 값이 없으면 지어내지 말고 묻기), 그 카드를 쓰는 때와 규칙(meta.json 문구 그대로), 바꿀 값(예시 JSON의 키와 공통 필드 설명), 카드가 맞지 않을 때 갈 llms.txt 주소, 그리고 카드 코드입니다. 영어 페이지는 영어, 한국어 페이지는 한국어 머리말과 카드를 줍니다.
- 이유: 지금까지 AI에게 건네는 것은 `.txt` 주소(AI용 링크)뿐이라, 주소를 열지 못하는 채팅 환경에서는 쓸 수 없었습니다. 카드 하나만 보고도 그대로 붙여 쓸 수 있어야 한다는 원칙을 AI에게 건넬 때도 지키도록, 규칙과 코드를 한 덩어리로 복사합니다. designbookmark.com/motion이 코드보다 프롬프트를 먼저 복사하게 하는 방식을 검토한 결과입니다.
- 버튼은 AI 종류별로 나누지 않고 하나만 둡니다. 내용이 같고, 고를 것이 적어야 하기 때문입니다.
- 크기: 머리말은 카드마다 1.5~2.5KB이고 나머지는 카드 코드입니다(KPI - Line 기준 전체 약 38KB). 한 장을 건네는 용도이며, 여러 장으로 화면을 만들 때는 llms.txt나 스킬을 씁니다.
- 갤러리에서 고른 선 모양(곡선 · 직선 · 계단)은 프롬프트의 카드 코드에도 그대로 들어갑니다.
- 카드 코드, 카드 주소, llms.txt, 스킬의 판단 규칙은 바뀌지 않았습니다. 새 공개 주소도 없습니다.
- 쓰는 법 4단계와 README에 프롬프트 복사를 적었습니다.
