# v0.49 · 움직임으로 읽는 차트와 대시보드 컨트롤로 갤러리를 다시 시작

갤러리를 새 방향으로 다시 시작합니다. 첫 화면에는 새 방향에서 승인한 블록 셋만 두고, 하나씩 채워 나갑니다.

## 새 블록

- **Budget Bars** (`bar-budget`): 항목마다 한도(예: 예산)를 세로 눈금으로 세우고, 지금까지 쓴 양을 막대로 채웁니다.
  - 한도를 넘긴 구간만 빨강입니다. 넘친 항목 수와 넘친 양의 합은 카드가 계산합니다.
  - 눈금이 먼저 서 있고 막대가 하나씩 차오른 뒤, 넘친 구간만 세 번 깜빡이고 멈춥니다. 막대가 차기 전에는 막대 자리를 미리 그리지 않습니다.
  - 예시는 채널별 광고비와 월 예산입니다.
- **Range Slider** (`control-range`)와 **Date Slider** (`control-date`): 손잡이 둘로 숫자 범위와 기간을 고르는 1단위 컨트롤입니다.
  - 값은 손잡이 위 말풍선에 늘 적혀 있고, 두 말풍선이 겹칠 만큼 가까워지면 '시작 – 끝' 하나로 합쳐집니다.
  - 값이 바뀌면 카드에서 `vzb-change` 이벤트(`detail: { name, value }`)를 보내고, 지금 값은 `data-vzb-value`에도 적습니다.

## 카드 공통

- 카드 안 JSON의 글자가 바뀌면 그 카드를 다시 그립니다. 컨트롤 이벤트를 받아 차트 카드의 JSON을 바꾸면 차트가 새 데이터로 그려집니다. 다시 그린 카드에는 `data-vzb-live`가 붙고, 움직이는 카드는 처음부터 재생하지 않고 마지막 장면을 바로 그립니다.
- 색은 Vizney의 Figma 팔레트에서 고릅니다.
  - 밝은 바탕의 데이터 색은 파랑(#007aff) · 분홍빨강(#ff2d55) · 주황(#ff9500)입니다.
  - 어두운 바탕(`"theme": "dark"`)은 Vizney 검정에 노랑(#ffcc00) · 흰색 · 회색입니다.
  - 좋음과 나쁨은 팔레트의 초록(#34c759)과 빨강(#ff3b30)입니다.
  - 밝은 바탕에서 글자에 쓸 때는 대비를 위해 검정을 섞은 한 단계를 씁니다(`--vzb-good-ink` #2a8040, `--vzb-bad-ink` #cb342b, 흰 바탕 대비 4.9:1 · 5.2:1). 팔레트 초록은 흰 바탕 대비 2.2:1이라 면에만 씁니다.
- 기존 카드도 같은 토큰을 쓰므로 밝은 바탕의 색이 바뀝니다(첫째 색 주황 → 파랑, 좋음 · 나쁨 → 팔레트 초록 · 빨강).

## 사이트

- 첫 화면 설명: '움직임으로 읽는 차트와 대시보드 컨트롤을 HTML 조각 하나씩에 담았습니다. …'
- 갤러리 타일
  - 카드 머리에는 예시 데이터의 제목이 나오고, 블록 이름('-' 없이)은 카드 아래에 있습니다.
  - 바탕은 어둡게 시작하고, 카드 오른쪽 위 단추로 밝게 바꿉니다.
- 기존 카드 48종과 차트 페이지는 다시 만들 때까지 숨깁니다.
  - 첫 화면, 검색, 사이트맵에서 내렸습니다. 검색은 첫 화면의 타일로 갑니다.
  - 공개된 주소, 카드 코드, llms.txt, 스킬은 그대로입니다.
- 공유 이미지(og.png, og-ko.png)의 문구를 '움직임으로 읽는 차트 · 대시보드 컨트롤과 함께'로 바꾸고, 카드를 Date Slider와 Budget Bars로 바꿨습니다.

## 확인한 것

- 1280px와 390px, 한국어 · 영어, 밝은 · 어두운 바탕에서 캡처해 겹침 · 잘림 · 줄바꿈을 확인했습니다.
- 복사한 코드를 빈 HTML에 붙여 단독으로 그렸고, 같은 카드 여러 장을 한 페이지에 넣었습니다.
- 마우스와 키보드로 조작하고, 슬라이더는 터치로도 확인했습니다. 동작 줄이기 설정에서는 마지막 장면이 그려집니다. 콘솔 오류는 없습니다.
- 숨긴 카드 48종을 v0.48과 같은 폭 · 같은 데이터로 찍어 비교했습니다. 크기와 배치는 모두 같고, 바뀐 것은 색(위의 팔레트 변경과 어두운 바탕에 맞춘 Sankey - Levels의 띠 색)뿐입니다.
- 컨트롤 두 개와 Budget Bars를 잇는 데모 화면(연결 스크립트 15줄쯤)에서 끌기, 트랙 누르기, 키보드, 바탕 전환 뒤에도 차트가 다시 그려지는 것을 확인했습니다.
