# v0.50 · 컨트롤 두 개: Filter Chips, Download Button

## 새 블록

- **Filter Chips** (`control-chips`): 정해 둔 항목 가운데 여러 개를 칩으로 고르는 1단위 컨트롤입니다.
  - 누르면 칩이 살짝 눌렸다 튀고, 고르면 체크가 그려지며 칩이 넓어집니다.
  - 맨 앞 전체 칩은 고른 수를 굴러가는 숫자로 보여 주고, 누르면 모두 고르거나 모두 풉니다. 몇 개가 걸려 있는지 늘 보여 필터를 건 채로 잊지 않게 합니다.
  - 모든 칩에 체크가 그려졌을 때를 기준으로 재서 두 줄을 넘으면 한 줄로 두고 가로로 밉니다. 고를 때마다 줄 모양이 바뀌지 않게 하기 위해서입니다.
  - 값이 바뀌면 `vzb-change` 이벤트(`detail.value`: 고른 항목 배열)를 보냅니다.
- **Download Button** (`control-download`): 화면의 차트 카드(`target`) 데이터를 CSV로 내려받는 1단위 컨트롤입니다.
  - 컨트롤로 거른 뒤의 JSON을 읽으므로 보이는 그대로 받습니다. 엑셀에서 한글이 깨지지 않게 BOM을 붙입니다.
  - 받기 전에 `vzb-download` 이벤트를 보내고, 페이지가 `preventDefault()`를 부르면 파일을 만들지 않습니다.
  - `shortcut`을 적으면 단추 안에 키캡을 그리고, 그 키를 누르면 키캡이 내려앉으며 받습니다. 입력 칸에 쓰는 중에는 shift만 붙은 단축키를 듣지 않습니다.
  - 받으면 화살표가 받침으로 떨어져 체크로 바뀌고, 이름이 흐려지며 바뀌고, 받은 행 수가 굴러 올라옵니다. 받을 데이터가 없으면 좌우로 떱니다.
- 공통 부품 `roll`(굴러가는 숫자)을 더했습니다.

## 확인한 것

- 1280px · 390px · 340px, 한국어 · 영어, 밝은 · 어두운 바탕에서 높이가 1단위(168px)로 맞는지 확인했습니다.
- 빈 HTML에 붙여 단독으로, 같은 카드 두 장과 함께 그렸습니다.
- 채널을 걸러 받은 CSV에 거른 4행이 그대로 들어가고 BOM이 붙는 것을 확인했습니다. 입력 칸에서의 단축키 무시, 페이지가 막았을 때 파일 없음, 대상이 없을 때의 떨림을 확인했습니다.
- 키보드(Tab, Space · Enter, 단축키)와 동작 줄이기 설정을 확인했고, 콘솔 오류는 없습니다.
- 다섯 블록을 이은 영어 대시보드에서 기간 · 예산 규모 · 채널 · 내려받기 · 바탕 전환 뒤에도 차트가 다시 그려지는 것을 확인했습니다.
