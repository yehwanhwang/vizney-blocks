# v0.56 · 여섯 장만 남기고 정리, 카드 id는 카드 이름

이전 방향(분석 화면용 정적 차트)에서 만든 카드와 차트 페이지를 모두 지우고, 지금 방향(움직임으로 읽는 차트와 대시보드 컨트롤)의 여섯 장만 남겼습니다. 카드 id는 카드 이름과 같게 맞췄습니다. 카드는 하나씩 다시 더해 갑니다.

## 주소가 바뀝니다

카드 id는 이제 카드 이름을 소문자와 하이픈으로 적은 것입니다. 가드가 이 규칙을 검사합니다.

| 카드 | 예전 id | 지금 id |
|---|---|---|
| Warning Bars | `bar-budget` | `warning-bars` |
| Share Waffle | `waffle-share` | `share-waffle` |
| Rank Lines | `bump-race` | `rank-lines` |
| Range Slider | `control-range` | `range-slider` |
| Filter Chips | `control-chips` | `filter-chips` |
| Download Button | `control-download` | `download-button` |

- 카드 코드 주소는 `/cards/<지금 id>.txt` · `.html`(한국어는 `/ko/cards/`)입니다. 카드의 `data-vzb`와 Download Button의 `target`도 지금 id를 씁니다.
- 예전 주소는 남기지 않았습니다. 없는 주소는 첫 화면으로 안내하는 404 화면이 받습니다.
- 갤러리를 다시 채우는 동안에는 카드 이름이 바뀌면 id와 주소도 함께 바뀝니다. 그래서 가드의 '공개된 카드 주소 유지' 검사와, 목록에서 내린 카드를 남겨 두던 장치(`retired`)를 뺐습니다.

## 지운 것

- 카드 49장: 첫 화면에서 숨겨 두었던 37장(KPI · 막대 · 라인 · 그리드 · 도넛 · 스캐터 · 트리맵 · 히트맵 · 워터폴 · 퍼널 · 와플 · 범프 · 생키 · 레이더)과 목록에서 내려 두었던 12장.
- 차트 페이지(`/bar/`, `/ko/bump/` 같은 종류별 화면 15개씩)와 그 화면에만 쓰던 탭 줄, 차트 종류 그림, 목적 색인(`purposes.json`), '고르기와 배치' 규칙.
- 예전 영어 주소(`/en/` 아래의 넘김 페이지와 파일 사본), 한 페이지 갤러리(`dist/`).
- 여섯 장이 쓰지 않는 공통 부품 14개(축 · 막대 · 선 · 표 · 생키 등)와 영어 번역표에서 쓰이지 않게 된 문구(165개 → 62개), 컨트롤 공통 스타일 파일(컨트롤마다 제 CSS에 한 줄로 옮김).
- 스킬 예시 세 개(매출 · 손익 · 성장 화면). 지운 카드로 만든 화면이라 새 예시 하나로 바꿨습니다.

차트 종류(막대 · 와플 · 범프)는 llms.txt와 스킬에서 카드 옆에 적는 분류로만 남습니다. 앞으로 더할 카드가 쓸 공통 도구(`core.js`, `chart.js`, `base.css`, 토큰)는 그대로 두었습니다.

## 다시 쓴 것

- 첫 화면 설명: "한도를 넘긴 값, 뒤바뀐 순위, 달라진 비중처럼 움직여야 보이는 변화를 그리는 차트와, 대시보드에 필요한 컨트롤입니다. 카드 하나가 HTML 조각 하나라서, 복사해 붙이고 JSON 값만 바꾸면 됩니다."
- 쓰는 법: 복사해서 붙이기 · JSON만 바꾸기 · 컨트롤과 잇기 · AI에게 맡기기의 네 단계와, 공통 필드 · 배치 · 색과 글꼴 · 알아 둘 것.
- llms.txt와 스킬: 차트 3종과 컨트롤 3종의 쓰임과 규칙, 그리고 '컨트롤과 차트 잇기'(이벤트, 처음 값 맞추기, 빈 결과, 같은 카드 두 장, 내려받기) 절과 스크립트 예시. 스킬의 체크리스트에 컨트롤 항목을 더했습니다.
- 스킬 예시와 플러그인 미리보기: 채널을 고르면 Warning Bars가 다시 그려지고 Download Button이 고른 결과를 받는 광고비 화면.
- README, 공유 이미지 도구(`tools/og.mjs`의 카드 id).

## 고친 것

- Rank Lines: 이름표 폭을 웹 글꼴이 오기 전에 재면, 같은 화면을 다시 열 때마다 이름표 열의 위치가 1~2px 달라졌습니다(v0.55에서도 있던 문제: 폭 1280px 타일에서 620.1px와 621.9px가 번갈아 나옴). 글꼴이 준비되면 다시 재도록 고쳐, 네 번씩 열어도 같은 값이 나옵니다.

## 확인한 것

- 카드 여섯 장의 단독 페이지를 v0.55와 같은 데이터 · 같은 폭(760 · 380px, 영어 · 한국어)으로 그려 견준 결과 픽셀이 같습니다. 갤러리 타일도 밝은 · 어두운 바탕에서 같습니다(Rank Lines는 위 고친 것의 차이뿐).
- 카드 코드(`.txt`)를 빈 HTML에 두 장씩 붙여 영어 · 한국어 모두 그려지고, 차트 336px · 컨트롤은 조작부 높이(39 · 28 · 44px)입니다.
- 미리보기 화면에서 칩을 풀고 켜면 Warning Bars가 다시 그려지고(값 · 한도 · 부제), 모두 풀면 빈 화면이 나왔다가 다시 고르면 돌아옵니다. 내려받은 CSV는 13행이고 화면의 값과 같습니다. 같은 화면을 한국어 카드로도 만들어 스킬 예시의 확인 결과를 맞췄습니다.
- 세 차트 모두 빈 배열(`"labels": []`, `"items": []`)에서 오류 대신 빈 화면을 그립니다.
- 첫 화면의 프롬프트 복사 · 코드 복사(보이는 바탕 포함) · 바탕 전환 · 찾기, 404 화면, 사이트 안 링크를 확인했고 콘솔 오류는 없습니다. 1280 · 390px 캡처에서 겹치거나 잘린 곳이 없습니다.
