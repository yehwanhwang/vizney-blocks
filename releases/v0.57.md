# v0.57 · 제목 옆 버튼: AI용 링크 복사(와 후원 자리)

첫 화면의 제목과 설명 오른쪽에 버튼 자리를 만들었습니다. 배치 값은 Vizney Styles의 같은 자리와 같습니다(설명 600px, 버튼 48px, 간격 10px, 720px 이하에서는 설명 아래 두 칸).

- **AI용 링크 복사 / Copy AI link**: llms.txt 주소(영어 `https://blocks.vizney.com/llms.txt`, 한국어 `/ko/llms.txt`)를 복사합니다. 여섯 장 전체를 AI에게 넘기는 길이 그동안 쓰는 법 4단계까지 내려가야 나왔습니다. 복사가 막힌 브라우저와 스크립트가 꺼진 곳에서는 링크대로 그 파일을 엽니다.
- **후원 / Sponsor**: 노란 주 버튼으로 GitHub Sponsors를 엽니다. Sponsors 프로필이 열릴 때까지 `build.mjs`의 `SPONSOR`를 비워 두었고, 비어 있는 동안에는 버튼을 그리지 않습니다. 주소를 적고 다시 빌드하면 나타납니다.

## 확인한 것

- 영어 · 한국어, 1280 · 900 · 390px에서 버튼 위치와 넘침 없음. 버튼이 둘이면 900px에서 설명 아래 왼쪽으로 내려가고, 하나면 오른쪽에 남습니다.
- 누르면 주소가 복사되고 버튼 글자가 1.5초 동안 '링크 복사됨'으로 바뀌며 폭은 그대로입니다. 복사를 막은 브라우저에서는 llms.txt로 이동합니다.
- 후원 주소를 넣은 빌드와 비운 빌드 모두 콘솔 오류가 없습니다.
