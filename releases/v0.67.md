# v0.67 · Date Picker 5주와 직접 입력, Range Slider 금액 입력, Bar Overflow 예산 레이블 자리

## 바꾼 것

- **Date Picker**
  - 달력을 6주에서 5주로 줄이고 칸을 36px, 날짜 원을 32px로 키웠습니다. 늘 6주를 그리면 칸이 촘촘해 읽기 어려웠습니다. 6주에 걸치는 달(1년에 서너 번)만 같은 높이(180px) 안에 6주를 넣어, 달마다 높이는 같습니다.
  - 날짜 자리에 `"today"`를 적을 수 있게 했습니다(보는 사람의 오늘). 예시 데이터는 고정 날짜 대신 `"max": "today"`로 두고 `value`와 `min`을 비워, 갤러리와 복사한 코드가 열 때마다 오늘까지 30일로 시작합니다. 과거로는 제한 없이 넘어갑니다.
  - 연월 제목을 누르면 열두 달, 한 번 더 누르면 열두 해 화면으로 넘어가 먼 달 · 해로 바로 갑니다. 키보드로도 됩니다(화살표 · Enter, Esc는 한 단계 돌아감).
  - 달력 맨 위에 시작일 · 끝일 입력칸을 두었습니다. 2026-10-01 · 2026.10.1 · 20261001 · 10/1/2026을 모두 읽고, 읽을 수 없거나 고를 수 없는 날짜는 칸을 빨갛게 두고 적용하지 않습니다. Enter로 적용하고 닫습니다.
- **Range Slider**
  - 끄는 동안 뜨는 분포 창의 막대 영역을 28px에서 84px로, 개수 글자를 14px로 키웠습니다.
  - 손잡이 아래 값을 누르면(손잡이에서 Enter) 시작 · 끝 입력칸이 열려 금액을 직접 칩니다. 친 값은 칸 간격에 맞추지 않고 그대로 쓰고, 6만 · 1.2K처럼 적어도 읽습니다. 값 글자에는 누를 수 있다는 점선 밑줄을 그었습니다.
  - 예시의 끄는 간격을 2만 원($20)에서 5,000원($5)으로 줄였습니다. 분포는 칸에 걸친 만큼 나눠 세므로 개수는 그대로 맞습니다.
- **Bar Overflow**
  - 예산(한도선) 레이블을 막대 사이 빈자리에서 선의 오른쪽 끝, 막대 칸 밖으로 옮겼습니다(이름은 선 위, 값은 선 아래). 데이터에 따라 자리가 바뀌어 뜬금없어 보였습니다.
  - 좁은 폭에서 넘친 양 글자가 서로 겹치면 모두 지우던 것을, 큰 값부터 자리를 잡고 겹치는 것만 빼도록 바꿨습니다(390px에서 넷 가운데 셋이 남습니다).
- 공유 이미지(og.png, og-ko.png)를 바뀐 Bar Overflow로 다시 만들었습니다.
- 규칙(CLAUDE.md)에 직접 입력 원칙, 기준선 이름 자리, 겹치는 레이블 처리, Date Picker 5주와 오늘 기준을 적었습니다.

## 확인한 것

- 밝은 · 어두운 바탕, 영어 · 한국어, 390px 폭에서 Date Picker(열두 달 · 열두 해 화면, 입력칸, 잘못된 날짜)와 Range Slider(끌기, 값 입력, Esc 취소, 화살표)를 조작하고 실제 시간으로 녹화했습니다.
- 한 페이지에 Date Picker 두 장과 Range Slider를 넣고 `vzb-change` 이벤트와 `data-vzb-value`가 카드마다 따로 바뀌는 것을 확인했습니다.
- Bar Overflow를 v0.66과 같은 데이터 · 같은 폭(760px · 390px)으로 비교했습니다.
- 콘솔 오류 없음.
