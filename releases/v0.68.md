# v0.68 · 검색하고 고르는 컨트롤 Select Menu, 움직임 규칙 넓힘

## 바꾼 것

- **Select Menu(컨트롤) 추가:** 국가 · 지역 · 매장 · 상품처럼 이름이 수십 개라 칩으로 늘어놓기 어려운 필터를 위한 컨트롤입니다. Filter Chips는 8개 안팎까지 맞습니다.
  - 단추는 Date Picker와 같은 300px 알약입니다. 고른 이름을 잇고 넘치면 '+남은 수'로 줄이며, 고른 개수를 굴러가는 숫자 배지로 보여 줍니다.
  - `options`에 `count`를 주면 줄마다 데이터 양을 막대와 숫자로 보여 주고, 목록이 펼쳐질 때 막대가 0에서 자랍니다. 고르기 전에 데이터가 어디 몰려 있는지 보입니다.
  - 검색칸에 치면 맞지 않는 줄은 접히며 사라지고, 맞는 글자가 굵어지며 밑줄이 그어집니다. 한글은 초성으로도 찾습니다(ㄱ → 경기 · 강원 · 경남 …).
  - `"mode": "one"`이면 하나만 고르고 고르면 닫힙니다. 아래에 자리가 없으면 위로 열리고, `align: end`도 됩니다.
  - 키보드: 열면 검색칸에 포커스, 위아래 화살표와 Enter로 고르기, Esc로 검색어 지우기 · 닫기.
  - 예시는 영어판 국가 18개, 한국어판 시·도 17개의 주문 수입니다. 갤러리에서는 1칸 타일이라 다섯 줄이 모두 빈칸 없이 찹니다.
- **움직임 규칙 넓힘:** 움직임은 시간에 따른 변화를 보여 주는 것뿐 아니라, 시계열이 아니어도 짚을 곳을 드러내는 것도 됩니다. 판단 기준은 '움직임을 빼면 그 부분이 덜 보이거나 덜 읽히는가'입니다. 첫 화면 설명과 README 첫 문단을 이 방향으로 고쳤습니다.

## 확인한 것

- 밝은 · 어두운 바탕, 영어 · 한국어에서 열기, 검색(초성 포함), 고르기, 모두 고르기 · 풀기, 검색어 지우기를 실제 시간으로 녹화했습니다.
- 하나만 고르기 모드를 화면 오른쪽 아래(`align: end`)에 두어 위로 열리는 것과, 한 페이지 두 장에서 `vzb-change`가 카드마다 따로 나가는 것을 확인했습니다.
- 갤러리 1280px · 390px에서 타일 반복과 배치를 확인했습니다. 콘솔 오류 없음.
