# v0.71 · 갤러리에서 펼친 달력과 목록이 카드 이름을 덮지 않게

## 바꾼 것

- **타일 칸 높이:** 336px(2단위) → 400px. 2단위 차트 카드와, 가장 긴 펼침인 Date Picker의 단추 + 달력(40 + 8 + 334 = 382px)이 다 들어가는 높이입니다. 그보다 낮은 카드와 컨트롤은 전처럼 타일 가운데에 둡니다.
- 갤러리 화면(사이트 CSS · JS)만 바뀌었고, 복사하는 카드 코드는 그대로입니다.

## 왜

- v0.69는 타일이 길어지지 않게 하려고, 타일 칸보다 긴 달력 · 목록을 타일 아래 줄(이름 · 복사 단추) 위로 겹쳐 띄웠습니다. 그 결과 Date Picker는 이름이 'Dat'만 보였고, Select Menu는 목록이 이름을 덮으며 아래에서 잘렸습니다. 처음 온 사람 눈에는 오류로 읽힙니다.
- 겹쳐 띄우는 대신 타일 칸을 펼침이 들어가는 높이로 두었습니다. 모든 타일이 같은 높이라 줄은 그대로 맞습니다.

## 확인

- 1440px(영어 · 한국어)과 390px에서 달력과 목록이 펼쳐져 멎었을 때, 달력 아래 끝은 이름 줄보다 9px 위, 목록 아래 끝은 22px 위에 있습니다.
- 달력이 열리는 0.4초쯤 동안은 단추가 올라가는 중이라 달력이 이름 줄에 잠깐 걸칩니다. 멎으면 걸치지 않습니다.
- 타일 높이는 한 줄 안에서 같습니다(1440px에서 516px).
