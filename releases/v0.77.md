# v0.77 · Butterfly Fold의 쓰임 문구를 공개된 동작에 맞춤

## 바꾼 것

- **Butterfly Fold의 '언제 쓰는지'(한국어 · 영어):** "항목을 짚으면 반대쪽 막대를 포개어"를 "적은 쪽 막대 끝에서 많은 쪽의 길이까지 반대쪽 색의 점선을 그어"로 고쳤습니다. "날갯짓처럼"도 "두 날개를 접었다 펼치는"으로 맞췄습니다.
- **Butterfly Fold의 규칙(한국어):** "항목은 적은 순서대로 위에서 아래로 그립니다"를 "`items`에 적힌 순서대로"로 고쳤습니다.
- **Waffle Flip의 규칙(한국어):** 같은 말 "나머지는 적은 순서대로 진한 회색부터"도 "`items`에 적힌 순서대로"로 고쳤습니다.
- 카드 코드와 움직임은 바꾸지 않았습니다.

## 왜

- v0.76을 검토하다 찾았습니다. 차이의 표시는 시안을 거치며 면 → 상자 → 점선 한 줄로 바뀌었는데(`releases/v0.76.md`), '언제 쓰는지' 문구에는 막대를 포갠다는 앞선 시안의 말이 남아 있었습니다. 이 문구는 llms.txt와 스킬의 카드 목록에 그대로 실려 AI가 카드를 고를 때 읽습니다. 같은 카드의 규칙과 README는 이미 점선으로 적혀 있었습니다.
- "적은 순서대로"는 '써 넣은 순서'로 쓴 말이지만 '값이 적은 순서'로도 읽힙니다. 영어판은 "in the order written"입니다.

## 확인

- v0.76 검토: 원본으로 다시 빌드해 생성 파일이 커밋과 같음(다른 파일 0개). 라이브의 카드 코드와 첫 화면 바닥글이 v0.76. 차트 가이드 링크(영어 · 한국어)가 실제 글로 열림.
- Butterfly Fold를 따로 그려 확인: 밝은 · 어두운 바탕, 영어 · 한국어, 1100px · 390px에서 글자 크기는 17 · 14 · 12px뿐, 390px에서 그림 안 글자 18개가 서로 겹치거나 카드 밖으로 나가지 않음. 호버 · 키보드 툴팁, 다시 보기, 다시 그리기(바로 그림), 빈 배열, 값 없음 · 0 · 같은 값, 같은 페이지의 다른 카드에 영향 없음, 동작 줄이기를 켠 브라우저에서도 재생, 콘솔 오류 없음.
- 나머지 카드 열 장의 멈춘 마지막 장면은 v0.75와 같음(1100px · 390px, 영어 · 한국어).
- 이번 변경은 문구뿐이라, 빌드 뒤 카드 코드에서 달라진 것은 버전 주석과 카드 페이지의 규칙 문구입니다.
