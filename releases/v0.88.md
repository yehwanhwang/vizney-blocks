# v0.88 · 갤러리: Date Picker 달력이 타일 밖으로 넘치던 문제 고침

## 고친 것

- **증상:** 첫 화면 갤러리에서 Date Picker 타일의 달력이 열려도 단추가 위로 올라가지 않아, 달력이 타일 아래 줄(카드 이름 · 복사 단추)과 아래 타일을 덮었습니다. Select Menu의 목록, Range Slider의 분포 창도 같은 이유로 비울 높이가 비어 있었습니다.
- **원인:** 갤러리 스크립트(`page/site.js`의 `fitTile`)가 펼침의 높이를 `requestAnimationFrame`과 `document.fonts.ready`에서 쟀는데, 두 시점 모두 문서를 아직 읽는 중(`readyState === 'loading'`)일 수 있습니다. 카드는 문서를 읽는 동안 그리기를 `DOMContentLoaded`까지 미루므로(`core.js`의 `mount`), 그때는 달력 · 목록 · 분포 창이 아직 없어 `--gt-dp-pad` · `--gt-sl-pad`를 지웠습니다.
- **고침:** 문서를 읽는 중이면 `DOMContentLoaded` 뒤 다음 프레임에 잽니다. 카드 코드는 바뀌지 않았고, 갤러리 화면만 바뀝니다.

## 근거

- 고치기 전(1400 × 1000 화면): 첫 `fit`이 190ms(`loading`)에, `DOMContentLoaded`가 213ms에 왔고, 15개 타일 모두 비울 높이가 비었습니다. 열린 달력이 타일(413–837px) 아래로 987px까지 넘쳤습니다.
- 고친 뒤: Date Picker 342px · Select Menu 316px · Range Slider 140px가 영어 · 한국어 첫 화면 모두에 적히고, 열린 달력이 타일 안(482–816px)에 들어옵니다.
